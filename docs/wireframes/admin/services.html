Lists all services, including inactive ones (GET /api/admin/services). Inactive services are hidden from clients and can't be newly booked; existing bookings stay (BR-5). A service with bookings can only be deactivated, not deleted; "Delete" appears only for a service with 0 bookings.

Edit service

At the client's place they pay a travel fee, set under Settings (C-10, A-11). A cleaner, for example, always goes to the client.
Changes don't affect existing bookings, which keep their price and duration (BR-4). Validation matches the API: unique name, price ≥ 0, duration 1–720 minutes.
